# IndustriaPY

Sistema de gerenciamento de estoque desenvolvido em Python para controle de peças automotivas. O sistema permite gerenciar o estoque, registrar movimentações e controlar o acesso dos usuários de acordo com seu cargo.

## Como rodar

Instale as dependências:

```bash
pip install pandas tabulate
```

Execute o projeto:

```bash
python main.py
```

## Funcionalidades

- Login de usuários
- Controle de acesso por cargo
- Cadastro de peças
- Entrada e saída de produtos
- Consulta de estoque
- Histórico de movimentações
- Alerta para estoque baixo
- Persistência dos dados em arquivos JSON

## Tecnologias

- Python
- Pandas
- Tabulate
- JSON
